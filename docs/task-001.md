## Рабочие допущения

Берём скриншоты за основу без дополнительных подтверждений; для секции Plans приоритет имеет утверждённая таблица из четырёх тарифов (Trial / Basic / Plus / Complete) при сохранении визуального стиля карточек `05-plans.png`. Недостающие детали подбираем в том же стиле и правим по сборке. Мобильные макеты VPN — иллюстрации приложения; мобильную адаптацию сайта выполняем отдельно. Оплата, авторизация и настоящий VPN не входят в эту задачу.

## Приёмка

1. В едином документе присутствуют семь секций ровно в порядке 01–07.
2. Якоря открываются напрямую, работают с клавиатуры и без JS; заголовки не перекрыты шапкой.
3. На 375/768/1440 px нет горизонтального скролла и потери CTA.
4. Все четыре кнопки выбора тарифа (`trial`, `basic`, `plus`, `complete`) обновляют demo-сводку (название и цену) без перезагрузки; неверный plan обработан.
5. Screenshot-сравнение выполняется для каждой секции, включая Why Luni.
6. Wishlist доступен с desktop и телефона; запись подтверждает бот, а не клиент.
7. Production-артефакт содержит один index.html и корректные локальные ресурсы; отчёт проверок приложен.
