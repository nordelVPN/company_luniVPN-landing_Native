# task-007 · Реализовать каталог и страницу тарифов

## Актуальный объём: единый лендинг

Plans — секция 05 #plans, не отдельная страница. Monthly/Yearly обновляют общий выбор и сводку #checkout без перезагрузки.

Основа: [requirements](requirements.md) и [task-001](task-001.md). Порядок: Home → The app → Why Luni → Support → Plans → Checkout → Account. Эта запись заменяет прежние требования об отдельных страницах и ожидании согласования количества экранов. Выполнение миграции и QA пока не подтверждены.

## Ранее зафиксированные детали и отчёты

Ниже сохранены детали прежней реализации. Упоминания MPA, отдельных HTML и старых зависимостей являются историческими; применять актуальный объём выше.


**Исполнитель:** Frontend  
**Статус:** запланировано  
**Первый показ:** карточки Monthly/Yearly из одного каталога и проверяемый выбор плана.

## Объём работ

- [ ] Создать единый каталог monthly/yearly по data-model.md: priceMinor/currency null, mode demo, available false означает отсутствие реальной покупки.
- [ ] Использовать один источник для статической разметки, getPlans() и дальнейшей сводки; создать только нужные методы сервисного фасада.
- [ ] Сверстать карточки по main_page_screen_4.png, общий выбор/ссылки и мобильную последовательность.
- [ ] Нормализовать planId по каталогу и формировать checkout.html?plan=monthly|yearly с учётом base path. До появления Checkout показывать объяснение вместо битой ссылки.
- [ ] Добавить целевые unit-проверки неизвестного planId и различия неизвестной/нулевой цены; не вычислять выдуманные скидки.

**Планируемые файлы:** src/data/plans.js, src/data/pages/plans.js, pages/plans.hbs, src/entries/plans.js, src/templates/partials/plans/*, src/modules/plan-selection.js, src/services/index.js, src/services/demo/*, src/utils/*.

## Рабочие допущения

**Зависимости:** task-005 и общие компоненты task-006. Финальный переход в Checkout — после task-009 и согласования task-002.

На момент постановки исходники frontend и package.json отсутствуют. Эта карточка описывает недостающую реализацию, а не выполненную работу. Стек и разделение слоёв берём из обновлённой архитектуры. Этап C, реальная оплата, авторизация и VPN в задачу не входят.

## Проверка результата

1. Monthly и Yearly имеют одинаковые данные в HTML и сервисе; неизвестная цена отображается как «—», не как ноль.
2. Выбор доступен клавиатурой; переключение не создаёт второго каталога или глобального mutable store.
3. После task-009 оба перехода передают правильный planId, включая запуск под /preview/; до этого нет ссылки на отсутствующий файл.
4. Карточки проверены на 375/768/1440 px и по референсу, результаты unit-проверок сохранены.
