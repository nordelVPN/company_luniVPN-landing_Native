## Проверка результата

1. Unit/E2E завершаются воспроизводимо; ошибка маршрута/ресурса проваливает проверку, а не маскируется наличием index.html.
2. Отчёт содержит версию кода, окружение, команды, expected/actual, passed/failed/not-run, артефакты и ограничения; ни один непройденный пункт не объявлен успешным.
3. Для этапа A заполнен 001-validation.md; если B включён, отдельные результаты Checkout/Account явно отделены от публичной приёмки.
4. Локальный прогон не выдан за выполненный GitHub Actions или публикацию. Для приёмки задачи не требуется запускать deploy.
