# LUNI-FRONT-001 · Единый лендинг LuniVPN

**Исполнитель:** Frontend. **Статус:** требования готовы к реализации, приёмка не выполнена.

Родительский объём совпадает с [task-001](../../task-001.md): один index.html, семь секций 01–07 из [list-screens](../../images/concept/desktop/list-screens/), включая Why Luni, demo Checkout и Account. Прежнее ограничение четырьмя публичными страницами отменено.

Порядок: Home → The app → Why Luni → Support → Plans → Checkout → Account. Общая шапка, якорная навигация, выбор плана с обновлением сводки без перезагрузки, адаптация всех секций. Wishlist реализуется совместно с task-012 и входит в пользовательский сценарий поставки.

Декомпозиция: task-005 — сборка одного HTML; task-006 — оболочка и Home/Why Luni; task-007 — секция Plans; task-008 — The app/Support; task-009 — demo Checkout; task-010 — demo Account; task-011 — проверка всей последовательности.

Критерии: [матрица](001-validation.md), [требования](../../requirements.md). Состав секций уже принят пользователем; согласование task-002 не является блокировкой вёрстки. Реальные платежи, аккаунты и VPN не входят. Отчёт реализации и результаты тестов пока не представлены.
