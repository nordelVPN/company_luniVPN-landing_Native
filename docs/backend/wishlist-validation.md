Проверить php -l всех PHP-файлов, Compose config --quiet и сборку образа. Зафиксировать версии PHP/Docker, результат HTTPS wrapper и права /data. Факт /health=200 не закрывает ни запись, ни реальную доставку.

## Сквозной прогон с собственным тестовым ботом

1. Указать URL бота в сайте и проверить переход, в том числе с узкого экрана.
2. Зарегистрировать webhook на актуальный публичный HTTPS URL; проверить info.
3. Отправить /start: приветствие LuniVPN, одна запись.
4. Повторить /start: новый ответ, по-прежнему одна запись, createdAt прежний.
5. Пересоздать контейнер bot без удаления volume: запись сохранена.
6. Проверить запрос без секрета через публичный origin: 403, нет изменения данных.
7. Проверить backup и восстановление в изолированном volume.
8. Сверить info: отсутствие новых ошибок и необработанного хвоста после прогона.
9. Проверить отсутствие токенов/персональных данных в frontend bundle, Git и публикуемых артефактах.

Если нет токенов/URL, этап отмечается not-run с причиной; локальный fake transport не заменяет Telegram.
