# ADR-001 · Статический одностраничный лендинг

**Статус:** принято по указанию пользователя; заменяет прежнее предложение MPA. Имя файла сохранено для существующих ссылок.

## Решение

Один index.html с последовательными секциями Home, The app, Why Luni, Support, Plans, Checkout, Account по PNG 01–07 из list-screens. Навигация по якорям, без клиентского router. Сохраняются Webpack, Handlebars, SCSS и vanilla JS; Node нужен для сборки.

## Причина и последствия

Пользователь определил продукт как один лендинг. Отдельные HTML и SPA не требуются для его разделов. Общая шапка и partials исключают дублирование. Выбор плана обновляет сводку в документе; прямая ссылка может передавать plan через query. Один набор metadata и robots относится ко всему лендингу.

Текущий код ещё имеет шесть записей манифеста. Миграция и QA обязательны; этот ADR не является отчётом о выполнении.

Wishlist остаётся отдельным PHP/Telegram-контуром. Checkout/Account — demo-секции; live API и оплата вне текущего объёма.
