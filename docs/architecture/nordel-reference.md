Изучен локальный проект `C:\Users\CifronPro\projects\work\ZiA\company_nordel-landing_Native`: package.json, webpack/pages.js, webpack/webpack.common.js, модули app-preview и i18n, compose.yaml, workflow Pages, документы frontend и backend и задачи FRONT-001/002. Сборки и сервисы Nordel в рамках этого анализа не запускались; его сохранённые отчёты не являются проверкой LuniVPN. Секреты из .env не читались.

В LuniVPN обнаружены README, docs/concept-specification.md и 18 PNG в docs/images/concept: 7 desktop, 10 отдельных мобильных экранов и 1 парный вид. Описание дизайна в новых требованиях основано на существующей спецификации; повторная визуальная приёмка PNG в этот проход не выполнялась.

## Факты и переносимые решения

| Область | Подтверждение в Nordel | Решение для LuniVPN |
|---|---|---|
| Статический frontend | package.json: Webpack, Handlebars, SCSS, vanilla JS | Предлагаемый базовый стек; точные версии закрепить при создании проекта |
| Многостраничность | webpack/pages.js: index и about, данные/стили/модули на страницу | Единый манифест для публичных страниц; состав страниц LuniVPN свой |
| Общие компоненты | layouts/main.hbs и partials, регистрация в webpack.common.js | Общий layout и повторяемые компоненты |
| Контент | src/data, отдельный словарь locales.json | Отделять контент от разметки и поведения |
| Демо приложения | app-preview.js меняет локальное состояние | Чётко обозначенная демонстрация без обещания VPN-соединения |
| Локализация | i18n.js, EN/RU, fallback, подключение в pages.js | Возможный последующий этап; RU для LuniVPN ещё не согласован |
| Документация | components, development, tasks, validation, qa | Сохранить структуру и трассировку до артефактов |
| Backend | Compose: site, PHP bot, ngrok, volume wishlist | Перенос с адаптацией включён пользователем: task-012, требования WL-01–14 |
| Доставка | workflow собирает build/prod и публикует Pages | Статика может размещаться отдельно; хостинг LuniVPN не выбран |

## Что нельзя переносить как требование

Nordel имеет собственные горы, синие токены, светлую/тёмную темы, тарифы Essential/Plus/Family, About и Telegram-вишлист. LuniVPN имеет кремово-зелёную графику, Monthly/Yearly, Support, Checkout и Account в концептах. Сходство назначения не подтверждает одинаковый функциональный объём.

JSON-вишлист Nordel не подходит как готовая модель подписок и платежей. Наличие мобильных PNG LuniVPN не означает, что браузерный сайт должен стать нативным VPN-клиентом.

## Замеченные расхождения документации Nordel

- landing-development.md и landing-components.md ещё сообщают об отсутствии переводов; FRONT-002, i18n.js и pages.js уже описывают/подключают EN/RU.
- Инструкция разработки требует перезапуска после изменения шаблонов и данных, но webpack.common.js уже содержит WatchPageSourcesPlugin и templateContent. Реальную работу watcher следует проверять, а не копировать прежнее ограничение.
- Отчёт FRONT-001 прямо отделяет сохранённые проверки Chrome от непроведённых Firefox/WebKit и отдельной проверки footer. Этот принцип необходимо сохранить.
- Юридические ссылки # и пустой Telegram URL — ограничения конкретного примера, а не стандарт готовности LuniVPN.

Вывод для документации: хранить одно нормативное описание каждого решения и ссылки на него; при изменении кода обновлять связанный документ и отчёт одновременно.
